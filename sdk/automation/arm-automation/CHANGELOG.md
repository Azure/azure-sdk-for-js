# Release History
    
## 11.0.0 (2026-07-27)
### Features Added

The @azure/arm-automation package has been upgraded to a new SDK generation that provides layered APIs, smaller bundles, and improved ergonomics. Starting from version 11.0.0, this release includes breaking changes.

To migrate existing applications, see the https://aka.ms/azsdk/js/sdk/migration. For more information, refer to the https://aka.ms/azsdk/js/sdk/quickstart.
